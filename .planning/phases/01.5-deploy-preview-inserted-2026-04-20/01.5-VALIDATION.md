## Sampling Rate

- **After every task commit:** Run `npm run test && npm run check` (quick; ~22s).
- **After every plan wave:** Run full suite `npm run test && npm run check && npm run build` (~90s).
- **Before PR merge:** Full suite green locally AND curl evidence recorded against preview URL (Task 2.2).
- **Max feedback latency:** 1.5s for unit tests; ~90s for full suite including build; curl checks complete in <5s.

### Category B: Deployed header spot-check (curl-automatable once PR is open)

Run after Netlify deploy-preview build succeeds. Substitute `$PREVIEW_URL` with `https://deploy-preview-{N}--{SLUG}.netlify.app`.

| Check | Expected response | Command |
|-------|-------------------|---------|
| HTTP 200 on / | `HTTP/2 200` | `curl -sI $PREVIEW_URL/ \| head -1` |
| HTTP 200 on /manifest.webmanifest | `HTTP/2 200` | `curl -sI $PREVIEW_URL/manifest.webmanifest \| head -1` |
| HTTP 200 on /service-worker.js | `HTTP/2 200` | `curl -sI $PREVIEW_URL/service-worker.js \| head -1` |
| D-07: SW no-cache | `cache-control: public, max-age=0, must-revalidate` | `curl -sI $PREVIEW_URL/service-worker.js \| grep -i cache-control` |
| D-08: immutable bundle | `cache-control: public, max-age=31536000, immutable` | Find an asset from HTML, curl it: see Task 2.2 Step 5 |
| D-09: manifest 3600 | `cache-control: public, max-age=3600` | `curl -sI $PREVIEW_URL/manifest.webmanifest \| grep -i cache-control` |
| D-10: icons 1yr | `cache-control: public, max-age=31536000` | `curl -sI $PREVIEW_URL/apple-touch-icon.png \| grep -i cache-control` (and manifest-icon-192.png, -512.png) |
| D-11: CSP in HTML only | Response headers have NO `content-security-policy`; HTML has `<meta http-equiv="Content-Security-Policy">` | `! curl -sI $PREVIEW_URL/ \| grep -i content-security-policy && curl -s $PREVIEW_URL/ \| grep -i 'http-equiv="Content-Security-Policy"'` |
| Pitfall 6: precache survived prod build | 20+ `"revision"` occurrences in compiled SW | `curl -s $PREVIEW_URL/service-worker.js \| grep -o '"revision"' \| wc -l` |
