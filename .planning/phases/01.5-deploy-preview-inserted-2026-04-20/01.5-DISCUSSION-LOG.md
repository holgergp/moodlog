## Cache + security headers

### Q: Which header profile for netlify.toml?

| Option | Description | Selected |
|--------|-------------|----------|
| Standard PWA (recommended) | SW must-revalidate, immutable assets, manifest short-cache, CSP single source (app.html) | ✓ |
| Defense-in-depth (CSP header too) | Duplicate CSP as HTTP header; belt-and-suspenders | |
| Minimal — Netlify defaults | No custom headers; risk of SW caching on corporate proxies | |

**User's choice:** Standard PWA
**Notes:** Single-source CSP beats drift from two copies. Standard cache rules for content-hashed assets are well-understood. Service-worker no-cache prevents the class of bugs where SW gets pinned to stale bundle forever.
